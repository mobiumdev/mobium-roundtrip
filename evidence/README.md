# Evidence

One folder per probe, each with its `RESULTS.md`. Kept here: what each
`RESULTS.md` cites that is small, which is the JUnit result of every run
(`junit.xml`), the scores (`score-*.txt`, `06-score.txt`) and the short
outputs of single runs (`*.txt`).

Not kept: the traces (`trace.zip`, with a screenshot before and after every
call), the screenshots, the HTML reports, the JSON results and the console
logs, about 420 MB. A `RESULTS.md` that names a folder such as
`01-original-traced/` refers to those. The commands under "Reproducing a
run" in the [README](../README.md) make them again.
